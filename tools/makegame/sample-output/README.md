# Showcase output

`BASS.exe` is a completed `makegame` showcase package for **Beneath a Steel
Sky, CD Talkie** by Revolution Software Ltd.

It demonstrates:

- a single dedicated Windows executable;
- custom package identity, title, icon, and defaults;
- metadata-selected `START.BAT` startup;
- an original game-data ZIP mounted from inside the embedded package; and
- persistent DOSBox Pure Standalone saves and settings.

Package details:

```text

Title: Beneath a Steel Sky
Startup: START.BAT
File size: 72,513,536 bytes
SHA-256: FD4621EA68B6F53509E1F966B3ABC9D48975D7457B2CD38382C7E73D18B09AD2
```
